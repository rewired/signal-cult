# Project maintenance

Keep `README.md` and `native/README.md` up to date whenever changes affect features, controls, presets, setup, build/install steps, versions or limitations. Update documentation in the same change as the implementation. Verify statements against source and actual checks; distinguish automated verification from in-host testing. Do not present local build artifacts as published releases.

Keep all user-visible web and OFX labels, hints, errors and preset descriptions in English. Use standard professional color-science terminology. Keep technical color-management settings independent of creative look presets.
